# Meta

このファイルは、このリポジトリ自体の位置づけ、主な成果物、運用上の前提を説明するためのものです。

このリポジトリはコード開発用ではなく、知識管理・調査管理用です。

## Main Artifacts

- Behavior Change investigation reports
- One page summaries
- Decision logs
- Lessons learned
- Research backlog

## AOSP Source

AOSP source is treated as primary evidence.

`frameworks-base/` は必要に応じて以下で取得します。

```bash
git clone https://android.googlesource.com/platform/frameworks/base frameworks-base
```

AOSPソース自体をこのリポジトリの主成果物とはみなしません。
