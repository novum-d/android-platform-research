# 未解決の疑問（Open Questions）

このファイルは、調査中に出た未解決の疑問と、その背景を後で確認できるように残すためのものです。

調査中に出た未解決の疑問を記録する。

## テンプレート（Template）

### Topic（トピック）

疑問（Question）:

背景（Context）:

状態（Status）:
- Open / Investigating / Resolved

記入例:
- 疑問: Android 17 の該当変更に compat Change ID が存在するか。
- 背景: 公式文書は targetSdkVersion 37 以上と述べるが、AOSP tag 未取得。
- 状態: Open
