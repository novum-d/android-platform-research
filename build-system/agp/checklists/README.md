# AGP migration checklists

AGP の version update を実プロジェクトへ適用するときに再利用する、version pair 共通の検出、変更候補、検証、rollback 手順を置く。

詳細調査と 1ページサマリを読んだ後に使用する。実行時は対象プロジェクト側の PR / issue / 実行用 checklist へ必要項目を具体化し、command result、対象 module、実変更、Human Decision をそちらへ記録する。このディレクトリの汎用 checklist には、複数プロジェクトへ再利用できる手順だけを残す。
