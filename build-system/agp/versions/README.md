# AGP versions

AGP の version update 調査を置く。

推奨ファイル名:

```text
agp-<from>-to-<to>.md
```

例:

```text
agp-8.7-to-8.8.md
agp-8.x-to-9.0.md
```

各ファイルは `../../templates/version-diff-template.md` を元に作成する。
