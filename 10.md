Section title: Safer Native DCL—C

Original text:
If your app targets Android 17 (API level 37) or higher, the Safer Dynamic Code Loading (DCL) protection introduced in Android 14 for DEX and JAR files now extends to native libraries.All native files loaded using System.load() must be marked as read-only. Otherwise, the system throws UnsatisfiedLinkError.We recommend that apps avoid dynamically loading code whenever possible, as doing so greatly increases the risk that an app can be compromised by code injection or code tampering.
